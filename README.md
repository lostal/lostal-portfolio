## Características

- **Diseño minimalista** con animaciones fluidas
- **Responsivo** y adaptado a todos los dispositivos
- **PWA** instalable con soporte offline
- **Tema dual** con detección automática del sistema
- **SEO optimizado** con sitemap y metadatos
- **Accesible** siguiendo estándares WCAG

## Estructura

```text
src/
├── components/   Componentes Astro
├── layouts/      Layout base
├── pages/        Páginas del sitio
├── scripts/      JavaScript
└── styles/       CSS
```

## Scripts

```bash
pnpm dev          # Desarrollo
pnpm build        # Build producción
pnpm preview      # Preview local
pnpm lint         # Linting
pnpm format       # Formateo
```
